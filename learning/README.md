# Learning route

[Project overview](../README.md) · [Scientific route](../science/README.md)

Start with the [Holevo bridge](anchor-and-bridge.md) for the physical question, selected textbook chapters, notation and research-specific proof ingredients. Then follow the [30-milestone map](milestones.md).

The map allocates 12 milestones to background and preliminaries, assembling the oscillator, quantum channel and energy-constrained communication framework. Its 18 narrative milestones connect the logarithmic-coordinate construction, arbitrary-code converse, protected subsystem and Gaussian-input comparison into the complete result. Each phase moves from individual objects to an integrated account.

These are shared scientific understanding targets. The linked topic pages contain the authoritative definitions and proofs; the [verification guide](../verification/README.md) explains the finite checks and their limits.
